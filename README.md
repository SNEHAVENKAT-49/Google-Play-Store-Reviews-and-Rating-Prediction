# Google Play Store Reviews Analysis

## Project Description
This project analyzes Google Play Store applications and user reviews to understand app ratings, reviews, and trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Dataset
- apps.csv
- reviews.csv

## Files
- DataCollection.ipynb
- DataPreprocessing.ipynb
- apps.csv
- reviews.csv

## Objectives
- Collect Google Play Store data
- Clean and preprocess the dataset
- Analyze app ratings and reviews
- Generate useful insights
